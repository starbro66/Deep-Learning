3. 기본 모델 구축 및 학습
이제 간단한 딥러닝 모델을 구축하고, 훈련시키는 과정을 설명합니다.

TensorFlow (Keras) 모델 예시:

python

from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Dense, Flatten

# 모델 생성
model = Sequential([
    Flatten(input_shape=(28, 28)),  # 28x28 이미지를 1차원 벡터로 변환
    Dense(128, activation='relu'),  # 은닉층
    Dense(10, activation='softmax')  # 출력층 (10개의 숫자 분류)
])

# 모델 컴파일
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])

# 모델 학습
model.fit(x_train, y_train, epochs=5)
PyTorch 모델 예시:

python
코드 복사
import torch
import torch.nn as nn
import torch.optim as optim

# 신경망 정의
class Net(nn.Module):
    def __init__(self):
        super(Net, self).__init__()
        self.fc1 = nn.Linear(28*28, 128)  # 입력층
        self.fc2 = nn.Linear(128, 10)     # 출력층

    def forward(self, x):
        x = x.view(-1, 28*28)  # 이미지 크기를 1차원으로 변환
        x = torch.relu(self.fc1(x))
        x = self.fc2(x)
        return x

# 모델 및 옵티마이저, 손실 함수 정의
model = Net()
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(model.parameters(), lr=0.001)

# 모델 학습
for epoch in range(5):  # 5번 반복
    for images, labels in train_loader:
        outputs = model(images)
        loss = criterion(outputs, labels)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

4. 결과 분석
훈련이 완료되면 테스트 데이터를 사용해 정확도를 측정합니다.

TensorFlow 결과 측정:

python

test_loss, test_acc = model.evaluate(x_test, y_test)
print('Test accuracy:', test_acc)
PyTorch 결과 측정:

python

correct = 0
total = 0
with torch.no_grad():
    for images, labels in test_loader:
        outputs = model(images)
        _, predicted = torch.max(outputs.data, 1)
        total += labels.size(0)
        correct += (predicted == labels).sum().item()

print('Test Accuracy: {:.2f}%'.format(100 * correct / total))
